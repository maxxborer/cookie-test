# cookie-test

## Подготовка окружения (доменов)

Нам необходимо добавить в hosts-файл следующие строки:

```lua
127.0.0.1   test.local
127.0.0.1   sub.test.local
```

Hosts-файл находится в следующих директориях:

- на Windows: `C:\Windows\System32\drivers\etc\hosts`
- на MacOS/Linux: `/etc/hosts`

Если вы используете MacOS/Linux, то можете выполнить только эту команду (она запросит пароль администратора для sudo):

```shell
sudo bash hosts.bash
```

Если вы хотите удалить строки из hosts-файла, то можете выполнить следующую команду:

```shell
sudo bash hosts.bash rm
```

Если вы используете Windows, то можете добавить строки вручную в `C:\Windows\System32\drivers\etc\hosts`.

## Подготовка проекта

### Установка зависимостей

```shell
yarn # ставим зависимости
```

### Разработка

```shell
yarn dev # запускаем в режиме разработки
```

### Сборка

```shell
yarn build # собираем
```

```shell
yarn preview # запускаем
```

После запуска в терминале будут ссылки для открытия.

Нажимайте на кнопки для тестов и наблюдайте за выводом document.cookie (на экране отобразится текущее значение cookie) или прямо в DevTools.
